# Beauty Parlor Management System
## Run without XAMPP
1. Install Node.js.
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm start`
5. Open `http://localhost:3000`

The frontend also works directly by opening `home.html`; registration, login and appointment demo data use browser localStorage. The Node.js backend provides SQLite database connectivity through API endpoints.
